> A modern, immersive, and interactive developer portfolio built with the latest web technologies. Designed to showcase skills, projects, and insights with a unique visual flair.

## ✨ Key Features

### 🎨 Visuals & Animations
- **Immersive Hero Section:** Features a dynamic profile reveal, text scrambling effects, and interactive video playback on hover.
- **Magic Mode:** A unique toggle that transforms the UI with glassmorphism effects, animated backgrounds, and shader-like visuals.
- **GSAP Integration:** Smooth entrance animations, scroll triggers, and complex timeline sequences for a polished feel.

### 📝 Content & Blog
- **Markdown-Powered Blog:** Renders rich content with syntax highlighting and custom typography.
- **Interactive Diagrams:** Embeds **React Flow** diagrams directly within blog posts to explain complex architectures (AIOps, MLOps, GitOps).
- **Tag Filtering:** Browse articles by categories and tags.

### 🤖 Interactive Elements
- **AI Chatbot:** A fixed, collapsible chatbot widget for quick engagement.
- **Dynamic Greeting:** A floating greeting popup in the hero section that cycles through friendly messages.
- **Animated Logo:** A custom component with glowing and spinning effects.

### 📱 Responsive Design
- **Mobile-First:** Fully optimized for all screen sizes, ensuring readability and usability on phones, tablets, and desktops.
- **Adaptive Components:** Navigation, layouts, and typography adjust seamlessly to the viewport.

## 🛠️ Tech Stack

- **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- **Animations:** [GSAP](https://gsap.com/) (GreenSock), [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Flow Charts:** [React Flow](https://reactflow.dev/)
- **Routing:** [React Router](https://reactrouter.com/)

## 🚀 Getting Started

Follow these steps to get the project running locally on your machine.

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- [npm](https://www.npmjs.com/) (or yarn/pnpm)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/GitNimay/new-portfolio.git
   cd new-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Visit `http://localhost:3000` to view the portfolio.

## 📂 Project Structure

```
src/
├── assets/          # Static assets (images, videos)
├── components/      # Reusable UI components
│   ├── ui/          # Generic UI elements (buttons, cards, etc.)
│   └── ...          # Feature-specific components (Hero, Contact, etc.)
├── context/         # React Contexts (e.g., MagicBackgroundContext)
├── data/            # Static data files (blog posts, diagrams)
├── hooks/           # Custom React hooks
├── pages/           # Page components (Home, BlogListing, BlogDetail)
├── lib/             # Utilities and helpers
└── App.tsx          # Main application entry point
```
