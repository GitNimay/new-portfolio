# Nimesh Kulkarni — Portfolio

A modern personal portfolio website built to showcase Nimesh Kulkarni’s projects, experience, skills, and writing in a clean, interactive format.

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- GSAP
- Framer Motion

## Highlights
- Responsive portfolio experience across desktop and mobile
- Dedicated sections for experience, projects, skills, education, and contact
- Blog support for sharing technical content and insights
- Performance-focused frontend setup with reusable UI components

## Getting Started
```bash
git clone git@github.com:GitNimay/new-portfolio.git
cd new-portfolio
npm install
npm run dev
```

## Available Scripts
```bash
npm run dev       # start development server
npm run build     # create production build
npm run preview   # preview production build
npm run lint      # run lint checks
npm run test      # run tests
```
